# AnoSecureKit Enterprise Security

## Current reporting status

```text
security contact: not yet published
private vulnerability intake: not yet activated
public disclosure channel: not yet activated
```

Do not submit vulnerability details, secrets, exploit material, customer data,
or private keys through public GitHub issues. This repository currently has no
published confidential reporting channel. Do not infer an email address or
contact from a personal profile. An activated private channel will be recorded
in this file before reports are accepted through it.

When a private channel is activated, reports should include the affected
Enterprise version or commit, backend profile, Community or AnoCrypto-C
identity, platform and toolchain, reproduction steps, impact, exploitability
assumptions, and proposed embargo constraints. Reporter identity and report
material will be limited to people needed for triage and remediation, subject
to applicable law and an activated operating process.

## Current product status

AnoSecureKit Enterprise `0.1.0` is pre-release/internal qualification material.
It is not generally available, not a production release, and has no active
customer support commitment.

```text
lifecycle_status: unsupported

active_customer_support: false

release_authorization: denied-or-unavailable

```

Internal ZIP/TGZ delivery artifacts are not customer releases. No KCMVP or
FIPS validation is claimed.
